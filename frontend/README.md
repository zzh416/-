# Frontend

面经综合助手的 React + TypeScript + Vite 用户界面。

- `src/components/`：资料、画像、清单、学习和模拟面试组件。
- `src/api/`：后端 API 客户端、请求缓存和前端数据类型。
- `src/App.tsx`：工作台入口与顶层状态编排。
- `src/index.css`：全局设计样式。

本地检查：

```powershell
npm ci
npm run lint
npm run build
```

完整项目推荐从仓库根目录使用 Docker Compose 启动，参见[启动步骤](../启动步骤.md)。
