# 前端设计约定

目标是让 GitHub 用户清楚找到下一步，同时保持长时间阅读题答的舒适度。

- 继续使用 React、Ant Design 和现有蓝色，不加入额外视觉库、远程字体或装饰动画。
- 采用简洁工作台：一条约 248px 的侧栏同时容纳功能导航和资料库，主区优先呈现资料与题答；顶栏只保留产品名称、服务状态与指南入口。
- 导航顺序为资料工作台、我的画像、复习清单、薄弱题复习、模拟面试；顶栏提供使用指南。使用指引可以折叠，步骤可自由选择，无题库也能直接基于画像面试。
- 颜色用于动作、状态与来源，配合文字标签；正文为深灰，次要文字仍保证可读对比。系统无衬线字体用于题干和界面，答案保留独立的衬线阅读样式。
- 8px 圆角、细边框、克制留白；避免大型营销首屏、渐变、强投影、随机装饰图和重复卡片。
- 窄屏将功能导航换为紧凑网格，资料库可折叠；所有交互支持键盘、可见焦点，弹层不超出视口。
- 使用指南覆盖有资料与无题库两种路径、题答复核、画像偏好、学习标记、模拟面试与AI答案来源。

参考依据：ui-ux-pro-max 检索得到的 Minimalism & Swiss Style 与专业工具场景相符，采用其层级、可读性、键盘与轻量交互原则。检索返回的营销页面结构和默认配色不适合本项目，布局与颜色沿用现有 Ant Design 工作台并按上述要求调整。
