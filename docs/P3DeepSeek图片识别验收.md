# P3 DeepSeek 图片识别验收

> 日期：2026-10-23
> 结论：DeepSeek 图片识别已接入并在本机启用；两张普通截图及实际队列检查通过。长截图、真实扫描 PDF 和图文混排 Word 的质量仍未完成验收。

## 1. 接入方式

DeepSeek 官方当前支持使用 `deepseek-flash` 接收图片输入，见 [官方视觉接口说明](https://api-docs.deepseek.com/guides/vision/)。项目使用官方 `/chat/completions` 接口，以 base64 传入图片；不上传到额外文件托管服务。

OCR 与文字抽取分别选择服务商：

```dotenv
TEXT_MODEL_PROVIDER=deepseek
OCR_PROVIDER=deepseek
DEEPSEEK_TEXT_MODEL=deepseek-chat
DEEPSEEK_OCR_MODEL=deepseek-flash
DEEPSEEK_OCR_MAX_OUTPUT_TOKENS=8192
```

两条链路使用已有 `DEEPSEEK_API_KEY`。模板默认仍是 GLM，当前本机已经明确选择 DeepSeek；任一服务失败都不会自动切换到另一家。`OCR_PROVIDER=glm` 可继续使用原 GLM-OCR 实现。

图片识别只转录可见原文，不回答问题、不补写答案；随后复用题答抽取、逐字来源校验和人工复核。图片内容作为待识别数据，不作为执行指令。OCR 本身仍可能少字或误识别，来源校验只能保证题答引用识别后的文字，不能证明 OCR 与原图逐字一致。

## 2. 文件路径与边界

- JPG/PNG 直接识别，保留现有 10 MiB 图片上传上限。
- 扫描页或含图 PDF 页由现有解析器拆成单页，再用本地 Poppler 转 PNG 后提交整页识别，保留原页码。不含图片且文字层可用的 PDF 页继续直接解析。
- Word 内嵌图片使用同一 OCR 选择器，保留原有段落和图片位置；普通文字段落不送 OCR。
- 单页 PDF 转图限制最长边 2048 像素、30 秒超时、10 MiB 输出；不会把多页 PDF 静默截成第一页。PDF/Word 上传上限仍为 25 MiB。
- DeepSeek 输出被截断、返回不合约结构、空文字、鉴权失败、余额不足、限流或服务不可用均有明确错误；不把不完整输出保存为成功正文。

新增系统依赖 `poppler-utils`。从旧镜像升级需要重新构建 API/worker；仅修改 `.env` 时仍需重新创建容器加载环境变量。命令见 [启动步骤](../启动步骤.md)。私有验收目录同时排除于 Git 和 Docker 构建上下文。

## 3. 普通截图真实结果

使用用户先前提供的两张普通截图；先对照独立 gold，再比较实际 DeepSeek OCR 与题目抽取结果。

| 指标 | Multi-Agent 截图 | LangGraph 截图 |
| --- | ---: | ---: |
| 预期 / 实际匹配题数 | 12 / 12 | 15 / 15 |
| 可见伪题 / 非法来源候选 | 0 / 0 | 0 / 0 |
| 正确保留无答案 | 12/12 | 15/15 |
| 轻微 OCR 字符差异 | 0 | 2 |
| 带答案配对质量 | 不适用 | 不适用 |

LangGraph 截图的两处差异为“根因那这一块儿”少“这”、一处“召回到了”少“到”；达到原有微小 OCR 差异匹配标准，但不等于逐字正确。没有恢复这些字符后再算成绩，也没有修改 gold 或阈值。截图均无答案，不能用这次结果证明带答案图片的配对质量。

首次联测暴露了原文字抽取提示词的歧义：“没有答案正文则返回空数组”可能被理解为 `items=[]`。同一份 OCR 文字的真实 A/B 调用中，旧提示返回 0 题，明确“保留每道问题，只将该题的 `answer_spans` 留空”后返回 12 题。正式提示已采用这两句澄清，第二张截图也复测得到 15 题。

记录分别保存首次结果和修复后的结果，不将失败运行改写成成功。图片 OCR 只调用一次，提示修复后复用其识别文字再次调用题答模型；这不是两次独立 OCR 稳定性测试。私有截图、逐题结果和上游诊断保存在本机 `.local-quality/deepseek-vision-first/`，不提交原文或密钥。

## 4. 工程与运行验证

- 新镜像完整隔离后端回归：**268 passed**，无跳过；包含真实 Poppler 单页渲染。临时数据库及文件目录已清理，保留一项既有 Starlette 弃用提示。
- 实际 API/Celery 队列：一张截图上传后进入 `READY`，自动整理 `SUCCEEDED`，12 题全部无答案；专用临时题目、资料及资料库已清理。
- 实际混合文字样本：4 题成功提取，2 题保留原文答案、2 题保持无答案，0 疑似漏题；测试记录已清理。
- API/worker 已使用新镜像重新创建，当前文字与 OCR 都选择 DeepSeek；用户原有资料及题目不自动重跑或改写。

## 5. 尚未证明的能力

本轮没有真实长截图、扫描 PDF 或图文混排 Word 的质量基准。模拟编排测试与 PDF 渲染测试不能替代真实文件验收；密集小字和长页在模型缩放后仍可能漏字，需要后续样本验证。扫描 PDF 中真正空白页触发空 OCR 结果导致文件失败的既有行为也仍待单独处理。

本轮只解决可选 DeepSeek 图片识别及直接影响无答案题的提示歧义，不调整 Word/PDF 严格评分门槛，不代表整个 P3 已放行；当前缺口继续以 [阶段验收记录](./P3阶段验收记录.md) 为准。
