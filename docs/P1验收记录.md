# P1 验收记录

验收日期：2026-10-20。

## 交付结果

P1 已形成可用的本机文字闭环：资料库 → 粘贴文字或上传 TXT/Markdown → 查看与修订原文 → 从来源或手动建题 → 编辑答案 → 写私人备注 → 关键词检索 → 刷新后继续读取。

数据由 PostgreSQL 持久化；API 和 Web 仅发布到宿主机 `127.0.0.1`。业务查询统一使用后台固定本地用户，客户端不提交 owner。创建接口使用持久化幂等记录，编辑使用乐观版本号。

## 浏览器验证

使用实际运行的 Chromium 页面完成以下流程：

1. 创建“面经”资料库。
2. 粘贴文字并查看版本与原文。
3. 从资料块建立问题，填写 Markdown 答案和代码块。
4. 添加私人备注，按答案中的小写英文关键词检索。
5. 刷新页面，确认资料、问答和备注仍存在。
6. 通过文件选择器导入 UTF-8 Markdown。
7. 在 390 px 视口检查布局；`body.scrollWidth` 未超过视口，问答卡片可正常阅读。
8. 输入包含 `<script>`、远程图片和 `javascript:` 链接的 Markdown：脚本节点 0、外部图片 0、危险链接 0，脚本变量未注入。
9. 最终干净标签页提交题目后，浏览器 console 的 error/warn 数量为 0。

所有浏览器验收资料及临时上传文件均已清理，未执行 `down -v`，未删除用户数据卷。
