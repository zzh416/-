# 复习状态与薄弱题管理

## 范围

题库与个性化清单允许手动标记未标记、已掌握、不熟悉、不会。首页新增“薄弱题复习”，默认显示不会、不熟悉和内容更新后需重新确认的题目；仍遵循当前技能及排除偏好。状态只表示个人自评，不是AI正确率评分，不改变原清单数量和快照。

模拟面试的明确不会题由用户逐条确认后加入；已有题关联题库，AI题和追问单独保留面试来源，不冒充原资料题。不会题的确认请求可重复提交，但不覆盖随后人工标记。不会自动将模型反馈当作参考答案保存。

本轮不做自动复习日程、通知、语音或AI补答案。AI反馈用于改进本次回答；AI补答案是未来为无答案题生成长期参考内容的独立能力，继续留待下一版本评估。

## 数据与接口

迁移0019增加学习记录。状态更新使用学习版本、当前题目/答案版本；删除原题时清理关联记录，内容更新保留自评并提示重新确认。

- `POST /api/v1/learning/lookup`：按当前页题目批量读取状态，最多100条。
- `PUT /api/v1/learning/questions/{id}`：版本化更新题库状态，首次expectedVersion=0。
- `GET /api/v1/learning/items`：实时筛选、按薄弱程度排序、分页和搜索。
- `PUT /api/v1/learning/items/{id}`：更新薄弱题或独立面试题状态。
- `GET /api/v1/learning/interviews/{id}/candidates`：读取本轮明确不会的题及确认状态。
- `POST /api/v1/learning/interviews/{id}/turns/{turnId}`：显式确认一题，持久化幂等。

## 使用步骤

1. 刷新页面，在资料库“问答”或“我的复习清单”的题目下选择“我的掌握程度”。
2. 首页点击“薄弱题复习”，默认只看需要复习的内容，也可按状态、关键词筛选和翻页。
3. 复习后改为“已掌握”即从默认列表移出；“全部已标记”仍可查看。“未标记”取消复习标记。
4. 题干或答案更新后会进入待复习并显示提示；核对后可以调整状态，或点击“确认当前掌握程度”保留原自评。
5. 模拟面试记录底部显示“本轮不会题待确认”。只有点击“确认标记为不会，加入复习”才保存；已经掌握的原题会按这次明确确认改为不会。之后的重复提交不覆盖更新过的自评。
6. 来源面试可从薄弱题卡片的“回看来源面试与反馈”打开。AI题和追问明确标为“面试生成题 · 独立保存”，没有自动参考答案。

已有题的学习记录随原题删除；拒绝了所有来源的隐藏题也不在薄弱清单展示。旧面试原题已修改、隐藏或删除时不能直接确认，需要先核对题库。当前偏好排除的题会暂时隐藏，原标记保留。掌握状态改变不会让正在进行的模拟面试或原推荐快照失效。
