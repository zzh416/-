# P2.5 公开动态网页提取验收记录

## 交付范围

- 保留一个“导入网页链接”入口，静态正文优先，空正文、JavaScript 空壳、安全重定向、匿名 403 或不支持的压缩响应自动进入浏览器渲染。
- 新增独立 Playwright/Chromium renderer。每个任务使用全新匿名浏览器上下文，不继承用户 Cookie，不挂载数据库、Redis、资料目录或模型 Key。
- 浏览器主导航、重定向、脚本和 XHR/fetch 都校验 HTTP/HTTPS、公网地址与 80/443 端口；禁用下载、Service Worker、WebSocket、图片、媒体和字体，并限制请求数、等待时间、HTML 大小、内存和进程数。
- 渲染后的 HTML 继续使用 Trafilatura 提取，只保存文字正文和 HTML 快照，不在阅读页执行来源网页脚本。
- 前端增加“正在运行网页脚本”阶段，以及登录、验证码和无章节 URL 场景的替代操作说明。

## 真实链路验收

- Renderer 容器以 `pwuser` 运行，根文件系统只读，清空默认 Linux capabilities 后仅加入 Chromium 沙箱所需的 `SYS_CHROOT`，并启用 `no-new-privileges`、1 GiB 内存与 256 进程限制。容器使用 [Playwright 官方 seccomp 配置](https://github.com/microsoft/playwright/blob/main/utils/docker/seccomp_profile.json)允许用户命名空间沙箱。
- `127.0.0.1` 等私网地址由渲染服务拒绝。
- `https://spa1.scrape.center/` 的动态 DOM 从 2.5 KB 空壳增长到约 28 KB，并出现脚本加载的电影正文；随后通过 API → Redis/Celery → Playwright → Trafilatura 完成并保存正文。

## 当前边界

- 仅处理匿名可访问、一个 URL 能表示目标内容的单个页面，不登录、不处理验证码、不复用用户浏览器状态、不整站爬取。
- 知乎、CSDN、公开语雀、GitHub 等采用同一条提取链路；平台仍可能随时改变反爬规则或页面结构，失败时返回明确原因，不承诺绕过访问限制。
- `ai-agent-guide.xiaofuge.cn` 当前选择的章节只存在网页内存中，地址栏不随章节变化，后端只收到站点首页 URL，无法知道用户选中了哪一章。该类私人/无状态章节链接留待后续方案。
- 浏览器路由在每次请求前重新解析并拒绝非公网地址；DNS 校验与 Chromium 实际连接之间仍存在很短的重绑定窗口。renderer 与敏感服务隔离且不持有密钥，以降低剩余风险；正式公网部署前可再增加出口网络层阻断或固定 IP 代理。
