# 文字模拟面试 v1

状态：已实现并验收，2026-10-26。用户确认新增逐题限时与盲区切换。

## 约定

- 独立“模拟面试”入口，复用当前简历画像、偏好与复习清单；题库优先，AI只补充题库不足的空缺，明确标记来源。不生成参考答案。
- AI先选择面试题及出题原因，用户可选备考预览或正式逐题模式。目标3–12道基础题，来源不足时宁可少出题；题目和筛选依据保存快照。
- 文字回答默认180秒，可在60–900秒调整，每题可手动加时；口头1–2分钟仅为参考。计时基于服务端截止时间，刷新不重置，支持暂停／恢复。
- 到时停止继续输入并提示提交当前回答、加时或换题，不自动提交未完成文字。模型等待、反馈阶段不计回答时间，追问另起计时。
- 提供“不会／不了解，换方向”。直接切换到不同主题，不调用模型继续追问；简短明确的“不会”等回答也走同一路径。同主题剩余题保守跳过，无其他方向则结束并说明原因。
- 回答后给简短模型反馈与一个可选追问，用户决定追问、下一题或结束；每个基础题最多2次追问。追问须引用回答原文，通过项目／题干依据、技能和偏好校验。模型建议不等于正确率评分。
- 答案和草稿持久化，乐观版本避免重复提交；异步模型任务有状态、失败恢复和旧尝试隔离。模型失败时仍保存作答并允许换题；出题失败可明确改用题库计划。
- 保存最近10次面试记录、作答和简短总结，不改动原题库／简历／复习清单。仅发送必要岗位技能、项目说明、题目和当前作答到当前文本模型；反馈阶段可附最多3000字符的已有适用参考片段，不发送完整简历或私人备注。

## 实施

新增会话表（有界JSON计划和轮次快照）、计划／回答反馈后台任务、版本化操作接口、文字面试界面与计时器。先覆盖未知答案零模型调用、主题切换、截止时间、暂停、重试／并发和owner隔离，再构建与验收。

使用现有GLM/DeepSeek配置。真实调用验收只使用合成内容；上线前备份，测试在独立数据库运行。

## 使用步骤

1. 刷新页面，在首页顶部点击 **模拟面试**。先确保“我的复习清单”已按最新画像、项目和偏好生成。
2. 选择综合或指定项目、目标题数、每题秒数及训练模式。打字默认180秒，范围60–900秒；“逐题模拟”在开始前隐藏题干，“备考预览”可以先查看完整计划与出题原因。
3. 点击“生成本轮面试计划”，检查准备数量后点击“开始逐题面试”。AI失败时可明确“改用已有题库清单”，不会将题库计划伪称AI生成。
4. 输入回答，草稿停顿后自动保存；最近未同步文字在当前标签页中缓存。关闭面板不会暂停计时，离开前请点暂停并确认草稿已保存。
5. 到时输入框暂时停止继续输入，保留已有文字；可提交、加时1分钟或换题。暂停／恢复保留剩余时长，刷新不会重新获得整题时间。
6. 明确不会时点击红色 **不会／不了解，换方向**。简短“我不知道”“没用过”“不懂”等也直接记录并换方向，不调用模型盘问；同主题剩余题跳过。暂无其他方向时提前结束并说明原因。
7. 正常回答后模型给出简短反馈，可选“继续追问”“下一题”；追问另起本题计时，最多两次。模型等待和反馈阶段不计回答时间。模型不可用时回答仍保留，可不等反馈直接下一题。
8. 结束后查看本轮作答、盲区和反馈。历史选择器可恢复最近10次记录；未结束会话继续或结束后才能新建另一轮。

## 接口与保护

- 新增 `interview_sessions`，记录owner、所用清单、版本、有界计划和轮次JSON、独立模型任务token及时间。草稿／操作都校验版本及当前题ID，过时提交返回409。
- `POST/GET /api/v1/interview-sessions`：创建与最近记录，创建支持Idempotency-Key；`GET /{id}`；`PUT /{id}/draft`；`POST /{id}/answer`；`POST /{id}/action`。
- 模型出题或反馈异步执行，重复队列消息不重复调用，用户转题／结束后迟到响应不会覆盖新轮次。失败或10分钟超时可重试，出题与每题反馈各最多3次。
- 画像、偏好或题库变化后记录标为历史，新出题／继续提问要求重新建立当前会话。草稿仍可保留并结束旧轮次。
- 正式逐题模式的计划接口在结束前不返回未揭晓的题干；可用参考答案仅供模型反馈，不通过面试界面返回给用户，不生成参考答案。
- 候选至多80题、题干合计40000字符，项目与候选总输入不超过60000字符；私有去重记录使用哈希，不在每次保存草稿时复制全部题库原文。出题完成后移除候选池。

## 本版限制

这是文字训练工具，不提供语音、严格考试监考或技术正确率评分。自动方向识别依赖现有技术词典，无法覆盖的题归入“通用基础”，选择不会时可能保守跳过更多通用题；可新建不同范围继续练习。模型反馈与语义相似去重仍需人工核对。关闭面板计时继续，只有明确暂停才停止；不生成缺失答案或标准解法。
