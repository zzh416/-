# P3 阶段验收记录

> 验收日期：2026-10-24
> 结论：P3 当前可取得样本范围已经完成，P4 随后已完成；长截图、扫描 PDF 和图文混排 Word 仍作为取得真实样本后的补充验收，不阻塞当前版本发布。AI 答案生成仍属于下一版本。

## 1. 当前可用能力

- 支持从文字、图片 OCR、PDF、Word 和网页解析结果中自动整理题目。
- 图片 OCR 可通过独立 `OCR_PROVIDER` 选择 GLM 或 DeepSeek；扫描 PDF 按单页本地转图，Word 内嵌图保留位置，失败不自动切换服务商。
- GLM 或 DeepSeek 按来源块分批抽取，支持标题式问题、编号问题、普通问句和跨块多段答案；通过 `TEXT_MODEL_PROVIDER` 显式选择，不在失败时自动切换。
- 模型候选必须逐字回指当前资料版本；单批异常时可保存其他批次的有效结果。
- 不同资料或资料版本中的等价题干会合并到同一道题，编号、Markdown、空格及结尾标点差异不会产生重复题；每次来源自己的答案和定位证据仍独立保留。
- 仅字符相似的题目不会自动合并。复核页会列出最多 3 道疑似重复题，由用户确认当前抽取是独立题目还是应拒绝。
- 同一来源块同时包含问题和答案时，会按答案起点切开题干；明显的回答陈述句默认进入“已排除”审核状态，仍可人工重置。
- 只有问题的资料可以保留为空答案，不生成占位内容或 AI 答案。
- 题库支持“全部 / 有答案 / 无答案”筛选、数量、分页和关键词查询。
- 用户可以手工修改问题、答案并给单题添加私人备注。
- 抽取完成后可以进入原文对照复核，逐条确认、修改、拒绝或重置；问题与答案引用使用不同颜色定位。
- 复核页支持勾选当前页题目并批量确认、拒绝或重置；批量请求采用全有或全无的并发校验，避免只改成功一部分。
- 用户可以删除错误答案，并查看题目、答案和复核状态的修改历史；每条历史可恢复到修改前内容，删除与恢复后的答案版本号保持递增。
- 系统会提示带问号、明确问句和编号题目式标题中的疑似漏题，可从精确原文范围补建题目。
- 顶部“我的画像”入口支持独立上传简历，复用图片 OCR、PDF、Word、Markdown 和 TXT 解析能力。
- 所选文字模型可从简历提取带逐字证据的目标岗位和技能候选；用户可确认、排除、编辑、补充或删除技能。本轮 DeepSeek 画像实跑只使用虚构简历，未发送用户真实简历。
- 画像修改按版本快照保存；日常筛选只需读取结构化画像，不必反复传输完整简历。
- 全局偏好支持优先/排除、题目/答案作用域、启停和删除，并区分 MySQL 与数据库通用知识。
- “我的复习清单”按已确认画像和启用偏好生成，题干与答案分别识别技术依赖，并显示进入、排除、排序和答案不适用原因；等价题干会合并并优先保留有答案的版本。
- 每次推荐运行固定画像版本、规则快照、题目/答案版本指纹和算法版本；画像、偏好或题库内容变化后，旧结果仍可回看并明确提示过期。

## 3. 关键缺口证据

当前 OpenAPI 已增加抽取复核、抽取安全重试、画像、技术目录、偏好规则和推荐运行接口。抽取重试使用幂等键并限制最多三次；已有来源范围会跳过，已复核或人工修改内容不会被覆盖。

数据库已经包含画像、画像版本、技能候选、偏好规则、推荐运行和推荐结果实体；推荐结果保存题目/答案技术依赖快照。前端已增加“我的复习清单”入口。

`QuestionOccurrence.review_status` 已能查询和变更。拒绝项会从普通题库隐藏，原始出处和复核状态仍保留；问题、答案和复核状态的后续修改统一写入修改历史，并使用版本或期望状态校验。错误答案可以删除，历史记录可以恢复；答案跨越删除和恢复后仍使用单调递增版本，避免旧页面覆盖新内容。历史功能上线前已发生的修改没有可回填的前值，因此不会显示在历史中。

疑似漏题是确定性辅助检查，不是完整性证明。它会排除 URL 查询参数等明显误报，只提示带问号、明确问句、面试指令和编号题目式标题；用户的确认/拒绝结果才是后续质量统计的可靠依据。评测器使用一对一题目匹配，并分别统计原始召回率、辅助召回率、用户可见准确率、答案状态准确率、排版归一后的答案内容完整一致率，以及不参与门禁的基础规范化字符串一致率。完整结果见 [P3 题答抽取金样本质量报告](./P3题答抽取金样本质量报告.md)。

独立答案候选不再需要单独建表：`QuestionOccurrence.answer_quote` 与 `answer_spans` 已按每次资料来源持久化答案全文和定位，题库当前答案仍由 `Answer` 保存。复核页同时展示“本次资料答案”和“题库当前答案”，两者不同时明确提示；用户主动删除或修改题库答案后，后续抽取不会静默覆盖。当前技术依赖来自版本化的确定性词典，推荐运行已经保存题干与答案依赖快照，因此本版本不再给题目增加一份容易失效的重复标签；以后引入模型语义标注或出现实际性能问题时再持久化。

## 5. 已知工程债务与版本边界

- `apps/web/src/App.tsx` 仍超过 1,100 行。个性化清单已作为独立组件实现；后续继续拆出资料、题库、画像和弹窗等页面组件。
- 前端生产构建存在约 1.1 MiB 单包体积提示。它不影响当前本地使用；页面继续增长时应结合路由/组件拆分做按需加载。
- 前端还没有组件级自动化测试；当前由 API 测试和真实浏览器冒烟覆盖主要入口，后续复杂交互增加时再补组件测试。
- 后端测试有一项 Starlette `TestClient`/httpx 弃用警告，当前不影响运行，应在依赖升级前清理。
- 当前身份是固定本机用户，只适用于单机个人使用。多人登录、鉴权和远程部署属于后续发布阶段。
- 偏好规则仍按行做并发版本检查；推荐运行已经保存画像版本、完整规则集合快照与题目/答案内容指纹，可解释和复现历史结果。
- DeepSeek 已接入文字题答、简历画像、图片 OCR 及质量工具；文字和 OCR 分别与 GLM 显式二选一。向量检索配置继续属于预留能力。
