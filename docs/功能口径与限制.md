# 功能口径与限制

本文说明当前版本的处理范围、数据来源和已知限制。操作步骤见[使用手册](../使用手册.md)，安装与排障见[启动步骤](../启动步骤.md)。

## 资料导入与解析

- 文字及 Markdown 文件上限为 1 MiB
- JPG 和 PNG 图片上限为 10 MiB
- PDF、DOCX 和 DOC 文件上限为 25 MiB，PDF 最多 100 页
- 批量链接每次最多 50 条，单条 URL 最多 2048 个字符
- 网页导入只处理匿名可访问的单个页面，不继承浏览器登录状态，不处理验证码，也不遍历整站
- 网页地址必须使用 `http://` 或 `https://`，服务会拒绝本机、私网、保留地址、凭证和非标准端口
- 公开网页先尝试静态正文提取；正文不足时，系统使用隔离的 Playwright 服务渲染 JavaScript 页面
- 图片、扫描 PDF 和 Word 内嵌图片需要配置光学字符识别（OCR）服务；未配置时资料会保留，并显示可重试错误
- 长截图当前按整张图片识别，不会自动分片或合并跨分片内容

## 题目与答案

“AI 自动整理”只提取资料中已有的题目和答案。原文没有答案时，题目保持无答案状态；系统不会把作者感想或“这道题不会”等文字自动当作答案。

模型结果必须能回指当前资料原文。不符合原文范围、重复或格式不合法的候选会被拒绝。疑似漏题是确定性复核提示，最多显示 100 条，不代表系统已经找到全部漏题。

同一道题可以保留多个来源。题目归一使用保守规则，不会仅凭语义相似就强制合并；不同 URL 的转载或不同格式的同一资料也可能被分别统计。

## 画像、偏好与复习清单

- 已确认技能、目标岗位和项目参与筛选；待确认或已排除项目不参与关联
- “排除”与“优先”规则作用于复习清单，不会删除基础题库
- 题干与答案分别判断适用性，因此题目可以保留而某个技术不匹配的答案被排除
- 项目关联只根据题干与项目中明确出现的技术或主题给出建议，不改变题目顺序，也不删除通用题
- 清单保存生成时的题目、答案、来源和筛选快照；题库、画像或偏好变化后需要重新生成

来源数量是去重后的资料来源数，不代表独立作者数或面试概率。近 180 天只统计已填写资料日期的面经来源；未知日期不会被删除，也不会用上传时间代替发布日期。

## AI 补充答案

AI 补充答案需要你逐题主动生成。生成结果先保存为“待核对”草稿；只有当前有效且已确认的版本，才能在没有资料或手写答案时作为后备答案进入新复习清单。

- AI 标识不会因编辑或确认而消失
- 新草稿、失败任务或被丢弃的草稿不会替换旧确认版
- 题目或所选上下文变化后，旧答案可能标记为过期
- 默认不发送完整简历；私人备注只有在你主动勾选后才发送
- 没有资料依据时，答案会标记为一般知识参考，不会伪造资料来源
- AI 无法证明你的个人项目经历，涉及个人实践时必须按真实情况修改
- 默认每天最多 30 次生成或重试，同时运行 1 个任务，单任务最多重试 3 次

AI 补答仅使用当前题目已关联的有限资料片段和你选择的结构化信息，不会跨资料库搜索答案，也不提供批量补答。

## 模拟面试与项目追问

模拟面试支持题库出题、AI 自主出题和混合出题。AI 出题会检查已确认技能、项目、排除规则和重复内容；当依据不足或模型持续返回不合格结果时，最终题量可能少于目标。

选择“不会／不了解，换方向”后，系统会跳过同主题追问。面试反馈用于点评本次作答，不是标准答案，也不会自动把题目标记为已掌握或不会。

项目追问链最多选择 3 道已关联题，每道最多生成 3 层追问。结果标记为 AI 推演，不视为真实面经，不生成答案，也不会自动加入题库。生成时只发送所选项目说明、种子题和必要约束，不发送完整简历、答案或私人备注。

## 掌握状态与导出

“已掌握”“不熟悉”“不会”由你手动确认。AI 反馈不会替你判断掌握程度；面试中不会的题也要确认后才进入薄弱题复习。

Markdown 备考包导出整份进入清单的题目，不受当前分页和页面筛选影响。它不会调用模型，也不会重新计算历史清单。你可以选择导出当前个人备注；无适用答案的题目只保留题干和来源。

## 数据与隐私

- PostgreSQL 和 Redis 数据保存在本机 Docker 数据卷
- 上传原件保存在仓库根目录的 `data/`
- API Key 保存在 `infra/.env`
- 本地备份默认保存在 `backups/`
- `infra/.env`、`data/`、`backups/` 和 `.local-quality/` 均被 Git 忽略
- 前端和 API 默认只监听 `127.0.0.1`

配置 GLM 或 DeepSeek 后，使用 AI 整理、画像提取、OCR、补充答案、模拟面试或项目追问时，完成该操作所需的内容会发送给对应服务商。本项目不是纯离线模型系统，也不适合在没有登录和多租户权限改造的情况下直接暴露到公网。
