## 已交付

- 图片、PDF、DOCX、旧 `.doc` 和公开静态网页统一创建后台解析任务。
- 原文件保存在私有 `data/` 目录，资料记录格式、大小、哈希、来源 URL 和网页抓取时间。
- PDF 提取文字层并识别无文字页；DOCX 提取标题、段落、表格和内嵌图片；旧 `.doc` 在隔离临时目录中调用无界面 LibreOffice 转换。
- 智谱 `glm-ocr` 适配器只从环境读取 Key，并对响应、超时、认证、限流和服务错误给出稳定错误码。
- 网页获取在 DNS 和连接层固定已校验公网 IP，拒绝本机、私网、保留地址、非 80/443 端口及自动重定向，并限制类型、大小和超时。
- 前端支持多格式上传和网页链接导入，轮询任务状态，显示阶段、错误和来源，并提供最多三次重试。

## 当前边界

- 只抓取无需登录且无需执行 JavaScript 的静态网页，不跟随重定向。
- GLM Key 已配置且真实图片 OCR 已通过。OCR 适配器使用带 MIME 类型的 Data URL；供应商认证、限流、连接和文件类型错误均转换为稳定错误提示。
- P2 输出是可修订文字；P3 自动抽取问题和原文答案、区分有答案/无答案并结合简历画像与偏好筛选。当前版本不生成缺失答案，AI 答案生成推迟到下一版本。

## 复核发现

P2 主流程可用，但严格对照最初架构仍存在混合 PDF 按页 OCR、DOCX 图文原位顺序、长图分片和逐页纠错差距。完整结论和 P3 前置任务见 `P2-P2.5复核与P3开工准备.md`。
