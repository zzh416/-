# 模拟面试出题来源

## 目标与合约

提供题库出题、AI自主出题、混合出题。无知识库用户可以先在“我的画像”上传简历、确认技能与项目，再直接选择AI自主出题；无需建立知识库或生成复习清单。追问仍由用户选择，每个基础题最多两次；保留每题时限和不会时换方向。

- BANK：从当前复习清单筛选已有题，按原顺序准备，不调用出题模型。来源不足可少于目标题数，不自动生成新题。
- AI：只依据当前画像的已确认技能/项目新出题，不读取题库。技能题标明技能依据，项目题保留逐字引文；没有确认技能或项目时明确提示补全画像。
- HYBRID：保留题库优先、AI补足的现有行为；技能题或项目题都需可核对依据。

创建请求新增questionSource，兼容默认HYBRID；recommendationRunId仅BANK/HYBRID必需，AI省略。迁移0020允许会话不关联推荐清单。旧会话按HYBRID读取。

AI出题仅发送必要目标岗位、已确认技能、指定范围的项目说明与偏好。BANK/HYBRID沿用候选题限制；所有来源都不生成标准答案。纯AI会话对画像/偏好版本校验，题库变化不使其失效。

## 使用步骤

1. 没有题库时，先在“我的画像”上传简历并确认提取的技能/项目；也可手动添加。至少有一项已确认技能或一个已确认项目。
   空资料库首页也提供“完善我的画像”和“开始模拟面试”入口。
2. 首页点击“模拟面试”，新建一轮，选择“出题来源”。有未结束的旧面试时，先继续或结束它，再新建。
3. 无当前可用题库时默认选择“AI自主出题”，无需先创建知识库或复习清单；有当前可用清单时默认“混合出题”。
4. 选择综合或指定项目、基础题数量、每题时间和训练模式。综合可按技能出题；指定项目则新题必须引用该项目说明。
5. “备考预览”可先查看题目和技能/项目依据；“逐题模拟”开始前隐藏题干。之后的作答、追问、时限、不会题确认和复盘沿用原流程。

题库与混合模式需要当前复习清单。题库来源不足时明确提示实际数量。AI/混合规划保留有效题、按缺额最多自动请求模型3次，并自动修复可重试的格式问题；仍不足时显示缺额和“出题检查详情”，未开始作答前可点“补足目标题数”。手动重试与补题合计最多3次。不会用不符合技能、偏好和项目依据要求的题凑数。AI失败可重试或结束后切换来源；自主模式没有候选题库，不提供“改用已有题库清单”的隐藏回退。详见[出题可靠性修复](./模拟面试出题可靠性修复.md)。

## 实施与兼容

- 会话JSON保存question_source、画像版本和偏好指纹；新增skill_basis标明已确认技能，项目依据沿用project_name/project_quote。基础题、追问和复盘分别显示来源。
- 旧会话缺少新字段时按HYBRID读取，原有推荐快照、学习状态与资料不重写。纯题库模式直接READY，AI/HYBRID仍异步规划。
- 显式选择“改用已有题库清单”后来源变为BANK。纯AI不读取题库候选、参考答案或题库去重哈希，新增题库不会中断本轮；画像/偏好变化仍触发版本保护。
- 0020仅放宽会话的推荐清单外键为空。存在纯AI会话时，直接降级到旧约束会被数据库拒绝，不会自动删除新会话；恢复旧版应使用升级前备份。
- 方向识别仍使用现有词典。仅有单一技术方向时，选择不会可能跳过多道相关题并提前结束；没有自动重新生成无限题目。
