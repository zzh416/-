# 下一步：个人备考包导出

状态：已实现并验收（2026-10-25）。前置检查：来源统计与抽取质量面板已完成，日期边界按应用时区修正。

## 目标与入口

在“我的复习清单”提供“导出 Markdown”按钮，将指定清单中全部进入清单的题目导出为一份 UTF-8 `.md` 文件。导出范围跨越全部分页；首期不把当前页面的 20 条误当成整份清单。

导出只使用已有题目、已有适用答案和已保存来源，不调用模型。技能与排除偏好仍是前置规则，已排除题目不进入默认备考包。

## 内容约定

- 文档开头记录导出时间、清单创建时间、画像版本、偏好快照、算法版本和导出数量。
- 题目顺序采用清单固定顺序，题目和答案使用 Markdown 标题清晰区分。
- 仅导出 `usableAnswerState=ANSWERED` 的答案；有来源答案但被当前偏好排除时，保留题目并注明“来源答案当前不适用”，不附带被排除的答案正文。
- 无答案问题只展示题目及来源，不补写答案或占位解释。
- 使用清单保存的来源快照，包含来源标题、URL、日期及面经／知识库数量。旧清单未记录的来源字段明确显示“未记录”，不能用当前来源伪装成历史快照。
- 备注可选择包含；读取导出时仍属于当前用户的题目备注，单独标注“导出时的个人备注”，不称为清单创建时的历史内容。
- 原文字符范围等未进入来源快照的字段，首期不伪造定位信息。
- 清单过期时显著注明历史版本；不在导出时自动生成新清单或改写历史。

## 接口与兼容性

增量接口：`GET /api/v1/recommendation-runs/{runId}/export?includeNotes=true`。`includeNotes` 默认 `false`；没有进入清单的题目时返回 409，未知或其他用户清单返回 404。

响应为 `text/markdown; charset=utf-8`，使用 `Content-Disposition` 提供安全文件名和 `Cache-Control: no-store`。沿用现有 owner 校验；未知或其他用户的清单返回 404。

导出不改变数据库、不触发外部模型、不读取简历原件、不把其他用户的备注或资料带入文件。

## 验收门槛

- 超过一页的清单完整导出，题目总数与导出范围一致。
- 排除题和不适用答案不因导出重新出现。
- 旧快照和当前备注来源明确，历史日期不被覆盖。
- 文件可离线阅读，代码块和中文正常，无新增模型费用。

## 使用方式

打开“我的复习清单”，在版本信息下点击“导出 Markdown”，核对范围后点击“下载 Markdown”。默认不包含备注，可勾选“包含导出时的个人备注”。历史清单也可导出，但文件和对话框均提示历史版本；需要最新筛选条件时先点击“重新生成”。空清单的导出按钮禁用。

文件名为 `面试备考包-清单ID前8位.md`。题干、资料答案分别使用三级标题，保留原有 Markdown 和代码块。文件记录应用时区的时间、画像及规则快照和清单版本；来源标题转义，来源链接仅保留不含凭证的 HTTP/HTTPS 地址。
