# 来源统计与抽取质量面板

实现日期：2026-10-25。对应 InterviewRadar 参考改进路线的第一步。

## 使用入口

1. 在资料库的“问答”页，每道题下方点击“查看来源详情”，查看面经来源、知识库来源、有效出现记录和近 180 天面经来源数。
2. 在资料详情填写已核对的“资料日期”，点击“保存日期”。未知时留空；点击“清空”后仍需保存。
3. 打开已整理的资料，可直接看到“抽取质量概览”，点击“查看质量与原文复核”进入原文对照。刷新页面后仍会读取当前资料版本的最近整理结果，无需重新调用模型。
4. 在“我的复习清单”中点击“重新生成”，新清单会保存当时的来源统计；旧清单提示尚未记录，不能用当前来源冒充历史数据。

技能和偏好继续决定题目是否进入清单、答案是否适用。来源统计只附加展示，本轮不修改排序权重、不补写答案、不搜索资料、不关联简历项目。

## 来源统计口径

- 同一用户下，按既有保守题干归一规则汇总等价题。不同原理或仅语义相似的题目不强行合并。
- 只统计仍存在的资料、当前资料版本、非 REJECTED 出现记录；也支持从原文块手动建立的题目。简历不进入资料来源统计。
- 同一网页按规范化 URL 计一次；去掉已知追踪参数，保留内容参数和路由 fragment，避免不同章节误合并。
- 无 URL 文件按原文件 SHA-256 合并。缺少哈希时按资料 ID 保守计数。
- 相同来源同时存在于面经和知识库时，来源总数只计一次，归入面经；面经数与知识库数之和等于总来源数。
- 相同来源的多次上传会合并为一个来源，但仍展示有效出现记录数与合并资料数量。
- 不同 URL 的转载以及同一资料的不同文件格式无法可靠自动辨认，页面明确披露这个限制。来源数不等于独立作者数，更不等于面试概率。
- 只有面经来源参与近 180 天计数；知识库内容不会因日期较旧被删除。日期未知的来源照常保留。
- 日期由用户核对后填写，不把创建时间、抓取时间或修改时间当作原文发布日期。重复来源的日期冲突时保持未知，等待人工修正。
- “今天”和近 180 天统计统一使用 `APP_TIMEZONE`，默认 `Asia/Shanghai`；时间戳仍保存 UTC，避免北京时间凌晨被误判为未来日期。
- 新复习清单保存来源快照。来源、日期或复核状态变化会影响内容指纹，旧清单标记过期，历史快照保持不变。

## 抽取质量口径

- 出现记录：本次运行保存的全部来源出现记录，包含已排除记录。
- 去重题目：全部记录所关联的不同题目 ID 数。
- 有效题目：至少有一条未排除记录的不同题目 ID 数。
- 待复核、已确认、已排除：按记录统计，覆盖完整运行，与页面分页和状态筛选无关。
- 原文有答案／无答案：只统计未排除记录的原文答案，与题库中后来手工修改的答案分开。
- 疑似漏题：原有确定性规则提示，最多返回 100 条；达到上限显示“至少 100”，不声称已列出全部。
- 最近尝试诊断：计划批次数、成功返回批次数、失败批次数、模型返回候选数、原文校验未通过数、同原文范围重复数。重试时重置诊断，已有题目仍安全保留。
- 旧任务没有保存过批次诊断时返回 null，显示未知，不从旧错误文本或最终题量推算。
- 所有指标都不是自动精确率或召回率；判断漏题和题答配对仍需原文复核或人工标注金样本。

## API 与迁移

迁移 `20261025_0014` 在既有表上新增可空日期、来源元数据版本、抽取诊断及清单来源快照，不改写已有正文、题目、答案或偏好。原 P1 数据迁移往返测试继续通过。

| 接口 | 增量能力 |
| --- | --- |
| `GET /questions`、`GET /questions/{id}` | 返回 `sourceStatistics` |
| `GET /questions/{id}/sources` | 获取当前来源聚合详情，owner 范围内访问 |
| `PUT /assets/{id}/source-metadata` | `sourceDate` 可空，`expectedVersion` 防止并发覆盖 |
| `GET /assets/{id}/question-extraction-runs/latest` | 获取当前资料版本的最近抽取运行，无则返回 null |
| `GET /question-extraction-runs/{id}/review-items` | 增加覆盖全部记录的 `quality` |
| `GET /recommendation-runs/{id}/items` | 返回创建清单时的来源快照，旧记录为 null |

## 验证结果

- 后端完整隔离回归：`300 passed`。使用一次性 PostgreSQL 数据库，自动清理。
- 新增测试覆盖：网页／文件去重、其他 owner 隔离、拒绝记录和旧版本排除、日期未知与未来日期拒绝、元数据并发版本、来源快照与过期、硬排除保留、原文校验诊断、质量摘要不随筛选分页变化、疑似漏题上限披露。
- 前端 lint 和生产构建通过；既有约 1.17 MB 主包提示仍存在。
- 5,000 题、20,000 来源块性能基准通过：题库首页 p95 90.31 ms，有答案筛选 94.38 ms，关键词搜索 106.47 ms，深页 91.90 ms。该基准验证整体查询开销，不代表高密度多来源场景或公网延迟。
- 真实浏览器：既有 CSDN 资料无需重跑模型即可显示 75 条出现记录、71 道有效题、4 条排除记录、30 条疑似漏题及历史诊断未知提示；来源详情将 CSDN 正确归入知识库来源，日期显示未知。
- 真实清单重新生成：80 题进入、5 题排除，与原技能偏好规则一致；新增来源标签正常展示。
- 六个 Compose 服务均 healthy；升级前备份保存在 `backups/before-source-quality-20261025/`，备份与截图均未纳入 Git。

## 复查补充

复查发现 UTC 日期与本机日历在午夜附近可能不同，已统一日期校验和近期计数的应用时区，并增加“北京时间当天可保存／次日拒绝／切换 UTC 后近期统计一致”回归用例。修复后完整隔离回归为 `302 passed`，前端 lint/build、Compose 配置与六服务健康复查通过。下一步导出约定见 [个人备考包导出设计](./个人备考包导出设计.md)。
