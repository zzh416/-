# P1 任务清单

状态：已完成。设计与依赖顺序见 `plan.md`，验收证据见 `../docs/P1验收记录.md`。

## 基础与数据

- [x] T01：API/Web 只绑定 `127.0.0.1`，校验 Host/Origin，数据库凭据用 `URL.create()` 安全组装。
- [x] T02：分离存活与就绪检查，数据库或 Redis 失败时返回 503，并设置超时和关闭连接。
- [x] T03：固定 Python 完整依赖、前端使用 `npm ci`，补充依赖卷与无 Key 启动说明，建立 Git 基线。
- [x] T04：Alembic 建立本地用户和 owner 约束；独立空库升级、降级、重复升级通过。
- [x] T05：页面可创建、选择、列出和删除空资料库，区分面经与知识库。

## 资料闭环

- [x] T06：粘贴文字/Markdown，保存原文版本、文本块和来源偏移；修订使用 `expectedVersion`。
- [x] T07：TXT/Markdown 文件入口支持 UTF-8/BOM、1 MiB 上限、扩展名和编码错误提示。
- [x] 检查点一：资料创建、导入、查看、修订、刷新持久化和迁移重放通过。

## 问答闭环

- [x] T08：可从资料块建题或建立手写题；答案可为空，来源不跨 owner/资料库。
- [x] T09：题干和答案可编辑并检查版本冲突；问题、答案、代码字体不同；Markdown 安全渲染。
- [x] T10：私人备注可新增、编辑和删除，按当前 owner 读取，编辑使用版本校验。
- [x] T11：按题干和答案关键词检索，支持资料库过滤、稳定排序和最多 100 条分页。
- [x] 检查点二：浏览器完成“导入 → 建题 → 编辑/阅读 → 写备注 → 搜索 → 刷新”。
