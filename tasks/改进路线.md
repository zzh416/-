# P4 后的增量改进路线

确认日期：2026-10-25。来源于 InterviewRadar 对比后的用户确认。

核心约束：技能和排除偏好继续控制清单；来源统计、项目关联和后续追问都是附加能力。

- [x] 第一步：来源统计与抽取质量面板。统计口径、API、界面、迁移和验收见 `../docs/来源统计与抽取质量面板.md`。
- [x] 第二步：从复习清单导出个人备考包，支持完整清单 Markdown、适用答案、来源快照和可选当前备注；不生成缺失答案。设计与验收见 `../docs/个人备考包导出设计.md`。
- [x] 第三步：项目画像、确认／编辑及已有题目的项目关联建议，保留通用题；原技能与偏好筛选保持。详见 `../docs/简历项目与题目关联.md`。
- [x] 第四步：项目追问链，区分已有题目与 AI 推演；保留项目说明／简历提取记录和种子题双重依据，支持历史与独立导出。详见 `../docs/项目追问链.md`。
- [x] 第五步：批量链接导入，支持同库复用、逐条状态、错误重试与历史。详见 `../docs/批量链接导入.md`。

2026-10-26 用户调整：主动搜索面经、搜索服务接入及平台自动采集移出当前版本，不作为下一步默认任务。

AI 生成缺失答案原先后置；2026-10-26 用户明确授权实施，见本文末尾新增阶段。

## 用户补充优先项（2026-10-26）

- [x] 独立文字模拟面试：个性化题目计划、逐题作答、用户选择追问与记录总结。
- [x] 每题可调时限、暂停／恢复、加时与刷新草稿；到时不自动提交。
- [x] 不会／不了解时及时切换方向，不继续围绕盲区追问。

实现和验收见 `../docs/文字模拟面试.md`；批量链接已完成，主动搜索移出当前版本，缺失答案生成继续后置。

## 复习闭环（2026-10-26）

- [x] 题库与复习清单共享人工掌握状态，不改变原筛选快照。
- [x] 薄弱题复习：不会优先，按当前画像/偏好筛选；内容变更后提示重新确认。
- [x] 面试明确不会题经用户确认后加入，AI题与追问独立保存并保留来源面试。

详见 `../docs/复习状态与薄弱题管理.md`。AI反馈不等于参考答案，缺失答案生成仍不在本轮范围。

## 无题库模拟面试（2026-10-26）

- [x] 题库／AI自主／混合三种出题来源；自主出题不要求知识库或复习清单。
- [x] 根据已确认技能或项目生成问题并标明依据，保留技能/偏好排除、可选追问和不会换方向。
- [x] 兼容旧面试记录、反馈与薄弱题确认；合成真实模型与隔离浏览器验收。

详见 `../docs/模拟面试出题来源.md`；这是AI训练题生成，AI补答案仍后置。

## AI补充答案与使用体验（2026-10-26 新授权）

- [x] 按需单题AI补答，独立草稿、编辑/确认/丢弃，来源永久标注；已确认AI后备进入推荐、学习及导出。
- [x] 简洁工作台导航、可折叠上手路线、无题库入口、应用内指南与主目录使用手册。
- [x] 隔离回归、真实合成模型、浏览器桌面/窄屏验收、备份迁移与升级记录。

本阶段替代此前“AI答案继续后置”的范围限制，详细设计见 `../docs/AI补充答案.md`。
