# 来源统计与抽取质量面板

目标：在现有技能与偏好筛选之上补充可解释来源统计和资料级抽取质量面板。

- [x] 定义统计口径与兼容 API；用真实数据结构确认能统计的指标。
- [x] 后端来源聚合：规范网页 URL / 文件内容身份；拒绝项、其他 owner、旧版本不重复计数；面经与知识库分开。
- [x] 资料日期可选人工维护；禁止拿抓取/导入时间冒充发布日期。
- [x] 抽取质量面板：全量复核数量、唯一题目、原文答案、疑似漏题及批次/校验诊断；旧任务未知指标明确返回 null。
- [x] 前端显示来源详情与质量面板，现有硬排除逻辑保留。
- [x] 隔离测试、迁移、前端检查、实际浏览器验收与文档同步。

约束：不推断全网热度，不宣称自动召回率；相同内容重复导入不冒充独立面经；本轮不生成答案、不关联简历项目、不搜索新资料。
