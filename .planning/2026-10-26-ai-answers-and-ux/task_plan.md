# AI补充答案与易用性改进

用户授权：新增AI补充答案并明确标注来源；改善面向GitHub使用者的前端审美、导航、步骤与操作指引。该授权替代原路线中AI答案延期的范围限制。

## 分工与顺序

- ai-answer：独立生成任务与答案草稿、确认/编辑/丢弃、版本及来源；后端代理负责API/模型/迁移/测试。
- answer-ui：单题生成与复核入口、所有答案消费页面的来源标识；依赖后端契约。
- workspace-ux：主壳导航、克制视觉、上手路径与应用内指南；并行实施，App由主壳代理独占。
- release-check：根代理统筹契约、文档、隔离端到端、真实合成模型、备份迁移与发布。

## 验收

- [x] 单题显式调用，生成草稿；编辑确认或丢弃；永久保留AI来源；原答案不覆盖。
- [x] 只有当前且已确认AI答案在无主答案时进入有效答案；推荐/学习/导出/面试来源正确。
- [x] 幂等、版本、owner隔离、并发/成本限额、失败重试、AI依据与个人经历边界测试。
- [x] 新用户能找到导入、整理复核、画像、筛选、练习；无题库路径同样清晰。
- [x] 桌面与窄屏视觉、键盘操作、加载/空/错误状态；不使用装饰性大横幅、花哨动画。
- [x] 完整隔离回归、前端lint/build、浏览器操作与合成模型验收。
- [x] README/启动步骤/使用手册/版本路线同步，备份与迁移后正式服务健康。
